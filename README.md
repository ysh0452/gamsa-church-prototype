# Knitus 화면 보기 (공개용)

교회 커뮤니티 앱 Knitus(니터스)를 링크만으로 볼 수 있게 올려 둔 곳입니다. 로그인 없이 열립니다.

- 처음 화면: `index.html`
- 개발한 앱 체험판: `app/`(신도 앱), `admin-web/`(관리자 웹), `admin-app/`(관리자 앱), `ops/`(운영자 백오피스)
- 기획 단계 클릭 프로토타입 v2.6: `member.html`, `admin.html`

교회 이름, 사람 이름, 금액, 계좌는 모두 예시입니다. 체험판은 서버 없이 미리 녹화한 예시 응답(`각 폴더/demo.json`)으로 움직이고, 저장 버튼을 누르면 저장하지 않는다고 안내합니다.

## 다시 올리는 법

- 기획 프로토타입: 비공개 저장소(감사교회/기획/프로토타입)의 최신 파일을 `node sync.mjs`로 복사
- 체험판: 비공개 저장소의 `tools/demo/record.mjs`로 예시 응답을 녹화하고, 앱 4개를 체험판으로 빌드한 뒤 `tools/demo/build-site.mjs`로 이 폴더에 복사

복사한 뒤 commit, push 하면 1~2분 안에 GitHub Pages에 반영됩니다.
